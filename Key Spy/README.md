# Key Spy

A keyboard-event playground that detects and displays which key(s) are being pressed.

## Features

- Displays the name of the last key pressed, on the provided box on the page.

## Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript (`keydown`, events, `event.key`, `event.code`.

## My Approach

Before writing any code, I inspected a raw `keydown` event in the browser console to see what data it actually carries, rather than being told upfront which properties to use. Then I moved on to testing it displayed on the page.

## How to Run

1. Open `index.html`,
2. Press keys (or hold multiple at once, or try Ctrl+S in the advanced version) to see the page react.
